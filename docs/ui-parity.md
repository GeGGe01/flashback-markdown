# UI parity target

The editor shell should visually track Flashback's reply editor rather than a generic developer tool.

Reference behavior for this batch:

- forced light presentation;
- breadcrumb row above the editor panel;
- light grey bordered panels;
- reply-style title bar;
- compact icon-first formatting toolbar;
- large white textarea;
- green primary action plus neutral secondary actions;
- advanced editor functions grouped below the core editor instead of crowding the primary toolbar;
- mobile spacing and proportions should follow the Flashback reply form closely while retaining Flashbackaren-only features.

The product remains a Flashbackaren tool, not a pixel-perfect clone or trademark copy.
