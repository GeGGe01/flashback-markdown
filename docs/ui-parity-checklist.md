# UI parity checklist

- Light theme is forced regardless of device dark mode.
- Breadcrumbs are underlined and spaced like the Flashback reply page.
- Editor is a bordered light-grey panel with a separate title strip.
- Core formatting toolbar is icon-first and visually flat.
- Advanced tools are grouped under the final toolbar control.
- Textarea is white, large, and the dominant surface.
- Save draft uses the green primary-action treatment.
- Editor mode, PM/forum mode, and drafts live under additional options.
- Preview remains available in desktop and mobile widths.
